How it works — end to end

1AI client

POSTs JSON-RPC 2.0 over HTTPS. Stateless — no session handshake. Key via header, Bearer, or ?key=.

→
2Server

class-wpxmcp-server registers the REST route, sets CORS *, routes initialize / tools/list / tools/call / ping.

→
3Auth + scope

hash_equals() key check → scope (full/editor/readonly) gated against each tool's risk.

→
4Handler

Tool closure runs native WP/Woo APIs. Exceptions become MCP isError results.

→
5Log

Every call → wp_wpxmcp_logs (tool, scope, success, IP). Front-end renders saved JSON-LD / robots / llms.txt.

full read + write + destructive · default, auto-created on activation
editor read + write, no delete/SQL
